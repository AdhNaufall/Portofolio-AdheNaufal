Cisco Network Simulation

BINUS Bekasi Campus Network Simulation

Project Overview

This project is a comprehensive network simulation for BINUS Bekasi campus, covering three floors with complex network configurations. This simulation is designed to provide optimal and secure connectivity for all campus facilities, including classrooms, laboratories, and administrative areas.

Main Features

  • Multi-Floor Topology

    Structured network design for three campus floors

  • Network Security

    Implementation of security protocols and network segmentation

  • VLAN Management

    VLAN configuration for network traffic separation

  • Routing Optimization

    Data path optimization for maximum performance
